# 📊 Indian-E-Commerce-Sales-Customer-Analytics-Dashboard
A 6-page Power BI dashboard analyzing a 9-table, ~659K-row star-schema dataset covering sales, customers, logistics, returns, and marketing performance for an Indian e-commerce business (2023–2025).

## Key Numbers
- ₹2.45bn total revenue · ₹197.29M total profit · 100K total orders · ₹24.50K average order value
- 58.24% on-time delivery
- ₹105.90M total refund amount
- 2.41 blended marketing ROI

Star schema with `orders` as the primary fact table, related to `customers`, `products`, `order_items`, `payments`, `returns`, `shipments`, `customer_reviews`, and `marketing_campaigns`.

## Dashboard Pages

| Page | What it covers |
|---|---|
| **Executive Overview** | Revenue/profit trend by month, order volume, AOV, on-time delivery % |
| **Sales & Revenue** | Revenue & profit by category, top products by revenue/units/margin |
| **Customer Analytics** | Gender split, orders by customer, loyalty tier mix, age group, customer status |
| **Logistics & Fulfilment** | Delayed shipments by warehouse city, on-time delivery rate |
| **Return & CX** | Return reasons, return rate % by category, review ratings, sentiment trend |
| **Marketing ROI** | Campaign-level ROI/conversion/CTR, channel-wise ROI, spend vs. revenue by campaign type |
